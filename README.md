RedFi & ShopFi - UNMSM

Aplicación móvil desarrollada para la comunidad de la Universidad Nacional Mayor de San Marcos (UNMSM), orientada a optimizar la vida universitaria mediante el acceso al seguimiento del transporte ("Bus Burrito") y un marketplace estudiantil seguro.

Características Principales
- Autenticación Institucional Obligatoria: Sistema de inicio de sesión seguro con Google que restringe el acceso exclusivamente a correos oficiales `@unmsm.edu.pe`.
- Perfiles Automatizados: Creación automática de perfiles de usuario en Cloud Firestore al primer inicio de sesión.
- Bus Burrito: Módulo informativo para la comunidad de la FISI y San Marcos.
- ShopFi: Marketplace estudiantil integrado.

Tecnologías y Librerías
- Lenguaje: Kotlin
- Interfaz de Usuario: Jetpack Compose (Material 3)
- **Autenticación & Base de Datos: Firebase Authentication (Credential Manager) & Cloud Firestore
- **Arquitectura: Componentes modernos de Android

Cómo Probar la Aplicación
